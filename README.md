# **CS61A — Structure and Interpretation of Computer Programs (2020FA–2024SP)**

This repository contains my completed solutions to **all programming assignments, labs, and projects** from UC Berkeley’s **CS61A**, one of the most well-known introductory computer science courses worldwide.

The work uses materials from 2020 Fall and 2024 Spring, and covers Python, Scheme, SQL, recursion, higher-order functions, object systems, data abstraction, interpreters, and more.

---

## 📚 **Course Overview**

CS61A focuses on **program design** using:

- **Functional programming**
- **Object-oriented programming**
- **Declarative programming**
- **Interpreters and language design**
- **Recursion & abstraction**
- **Data structures & algorithms (intro level)**

All assignments are written in **Python**, **Scheme**, or **SQL**.

### **3. Scheme Interpreter (Capstone Project)**

A full interpreter for a subset of **Scheme**, implemented entirely in Python.

**Features:**

- Tokenizer & parser
- Evaluation rules for Scheme expressions
- Implementation of **environments** & lexical scoping
- Support for:
    - `lambda`
    - recursion
    - higher-order functions
    - user-defined procedures
    - built-in primitives
- REPL with tail recursion behavior

This project demonstrates deep understanding of **interpreters, environments, language semantics, and functional programming**.
